# Portfolio 2025

A modern portfolio website built with React, RasenganJS, and TailwindCSS.

## Tech Stack

- [RasenganJS](https://beta.rasengan.dev/docs) - Modern React Framework
- [React](https://react.dev/) (v19)
- [TailwindCSS](https://tailwindcss.com/) (v4)
- TypeScript
- Vite

## Getting Started

1. Install dependencies:

```bash
pnpm install
```

2.Start development server:

```bash
pnpm dev
```

3.Build for production:

```bash
pnpm build
```

4.Preview production build:

```bash
pnpm serve
```

## Project Structure

```code
src/
  ├── app/          # Application components
  ├── assets/       # Static assets
  ├── styles/       # CSS styles
  ├── index.ts      # Entry point
  ├── main.tsx      # Main React component
  └── template.tsx  # HTML template
```
